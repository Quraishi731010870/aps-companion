EXECUTIVE OVERVIEW
The product

One platform, three user-facing layers

An Afghanistan-focused electronic-money and payments prototype built to demonstrate a modern, secure and observable financial-platform architecture.

The source uses both Afghan EMI and AfghanPay. A final branding decision should standardize the name before external release.

SECURITY
Identity and authorization

Separate controls for mobile and admin

Mobile authentication

  • Short-lived JWT access tokens
  • Hashed refresh tokens
  • Persisted sessions and devices
  • Secure client token storage
  • Logout and session revocation

Administrator authentication

  • Secure HTTP-only session cookie
  • CSRF token protection
  • Role-Based Access Control
  • Backend permission guards
  • Audit records for sensitive changes

READINESS
Honest project status

Implemented versus production-required

Implemented in the repository

  • Flutter wallet and payment flows
  • React administration portal
  • Executable NestJS backend
  • PostgreSQL/Prisma migrations
  • Authentication, RBAC and audit foundations
  • Swagger, ISO adapter and monitoring
  • Docker development environment

Required before financial production

  • Regulatory and legal approval
  • Real EMI/core-banking gateway
  • PCI-compliant tokenization
  • KYC, liveness, AML and sanctions screening
  • Double-entry ledger and reconciliation
  • Penetration testing and hardening
  • HA, backups and disaster recovery
